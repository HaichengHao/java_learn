你这段代码的核心是：**`Integer.valueOf("200")` 把字符串变成包装类对象，`intValue()` 再把包装类对象里的 int 值取出来。**

### 基本类型和包装类有什么区别？

| 对比点 | 基本类型 `int` | 包装类 `Integer` |
|---|---|---|
| 本质 | 不是对象，只是值 | 是对象，属于引用类型 |
| 存储 | 通常直接存值，效率更高 | 对象存在堆中，变量存的是引用 |
| 默认值 | `0` | `null` |
| 泛型/集合 | 不能直接放进 `List<int>` | 可以放进 `List<Integer>` |
| 方法 | 没有方法 | 有 `intValue()`、`valueOf()` 等方法 |
| null | 不能为 null | 可以为 null |



所以包装类就是给基本类型“套了一个对象外壳”，让它能参与面向对象的操作，比如放进集合、使用泛型、表示 null。

### 你代码里的两行

```java
Integer i = Integer.valueOf("200");   // 字符串 → Integer 对象
int num = i.intValue();               // Integer 对象 → int 值
```

`Integer.valueOf("200")` 会解析字符串 `"200"`，返回一个 `Integer` 对象。  
`intValue()` 是 `Integer` 的实例方法，作用是把对象内部保存的 int 值取出来。

### 注意两点

1. **Java 5 以后可以自动装箱/拆箱**，所以这两行也可以简写：

```java
Integer i = 200;      // 自动装箱
int num = i;          // 自动拆箱
```



2. 你现在的 `main` 方法少写了 `public`，正确写法是：

```java
public static void main(String[] args) {
```

否则程序可能无法正常启动。

### 简单记

- **基本类型**：轻量、高效，适合普通计算。
- **包装类**：是对象，适合集合、泛型、需要 null 的场景。
- **`valueOf()`**：把字符串或基本类型变成包装类对象。
- **`intValue()`**：把包装类对象变回基本类型 `int`。
